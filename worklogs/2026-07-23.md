## 完成進度

- fabLoader 新增獨立 `build loader`／`build loader min` 命令契約：一般 build 只產生 `dist/fabLoader.js` 與 `dist/fabLoader.min.js`，min build 只保留壓縮版；Loader 仍不納入 `build all` 或逗號多範圍 build。
- Diagram source／正式 Demo 會透過 fabLoader `mountHtml('#test', './test.html')` 將 `demo/test.html` 插入 `#test`，並等待內含 script 執行完成後才結束 queue。
- fabLoader 鏈式 CSS API 由複數 `.styles()` 更名為單數 `.style()`；字串載入單一 CSS，陣列平行載入一組 CSS，舊 `.styles()` 不保留。
- fabLoader `.script()` 新增陣列語法：字串維持循序載入，陣列內 scripts 平行載入且 queue 等待整組完成後才繼續；Diagram Demo 以同組平行載入互不相依的 Day.js CDN 與 FabUI core。
- 正式版 Diagram Demo 永久保留透過 fabLoader chain 載入的 jsDelivr Day.js 1.11.13 CDN，頁面會在既有狀態列顯示實際載入與日期格式化結果；獨立 `test/fab-loader-cdn.html` 測試頁同樣保留。
- fabLoader 的 `queue()` 改為選用；從頂層 `style()`、`script()`、`module()` 或 `run()` 開始時會自動建立互不干擾的獨立 queue，Diagram Demo 已移除不必要的 `.queue()`。
- fabLoader 新增 LAB.js 風格的 `queue()`，以 `style()` 平行等待 CSS、`script()`／`module()` 依序載入、`run()`／`done()` 插入 callback、`catch()` 統一處理錯誤，讓使用頁面不必自行撰寫 Promise chain；Diagram 正式 Demo 已切換至 queue 語法。
- 正式版 Diagram Demo 除 `fabLoader.js` 外不再直接引用任何外部 CSS／JavaScript；FabUI core CSS／JS、Diagram CSS／JS、Theme Loader、Demo script 與 module controls 全部改由 fabLoader 依相依順序載入。
- 新增獨立、無相依的實驗性 `fabLoader` browser global，支援 JavaScript／CSS 動態載入、圖片預載、HTML 記憶體快取，以及將 HTML 掛載到指定元素並依序執行內含 script；正式版 Diagram Demo 已先行試用。
- 完成全庫第二輪錯誤、重構與效能審查：FabGrid nested binding path 改為有上限的快取，local／TreeGrid 多欄排序先為每列準備排序值，避免 comparator 重複拆 path、轉 Date 與 lowercase；TreeGrid 收合查詢改用同步 `WeakSet`。新增 `npm run benchmark:grid`，固定以 20,000×50、共 100 萬資料格量測 binding、全域搜尋、雙欄排序與虛擬化上限。
- 精簡 Grid 捲動熱路徑：scroll render 重用現有 layout，垂直捲動且水平欄位範圍未變時不重建 Header／Footer，也不重畫 Pager；內建遠端 Fetch 在較新 load 開始或 Grid dispose 時會中止舊 request。Chart nested binding 同樣改用有上限的 path cache，PivotWorkspace `pointercancel` 會恢復起始 pane／chart 尺寸且不提交變更。
- 完成全庫第一輪錯誤、重構與效能審查：Chart 在 `observeData: false` 時不再建立定時輪詢，runtime 切換 observation／interval 會正確重啟或停止；Grid popup 的 document pointer listener 改為只在右鍵選單、Filter 或欄位選擇器開啟期間綁定，支援 `ResizeObserver` 時也不再重複綁定 `window.resize`。
- 修正跨元件非同步與互動生命週期：Gantt 的 Splitter／Task pointer listener 由共用 interaction lifecycle 管理，`pointercancel`／`dispose()` 會立即解除並放棄預覽；Tabs 與 Panel 會忽略已關閉、已銷毀或被新 request 取代的遠端回應，並在可用時取消舊 Fetch。
- 修正 HtmlEditor 對話框與圖片讀取競態：舊對話框的延遲 close 不會誤關新對話框，FileReader 在對話框關閉或 editor dispose 時中止且不再回寫已銷毀 DOM；`selectionchange` 只在可視化編輯區聚焦期間監聽。
- 新增 FabGrid `showFullscreenMenu` option，預設為 `false`；只有設為 `true` 時，Header cell 右鍵選單才顯示 Grid 全螢幕／離開全螢幕項目，不影響 `toggleFullscreen()` API 或其他選單功能。
- 新增 FabGrid `showRowHeaderMenu` option，預設為 `false`；只有設為 `true` 時，Header cell 右鍵選單才顯示「列號」子選單。隱藏此項目不改變目前列號欄狀態或 `setShowRowHeaders()` API，其他選單項目維持不變。
- 修正 Grid 右鍵選單：`filterMode: false` 時不再顯示「清除篩選」，啟用任一 filter mode 時維持顯示；列號、Excel／CSV 匯出與全螢幕項目不變。
- 補齊遠端資料更新事件：初次載入、換頁、排序、篩選或 `reload()` 的有效成功回應套用新 rows 後，會以 `{ rows, remote: true }` 觸發 `itemsSourceChanged`，順序位於 `selectedRowChanged` 與 `loadSuccess` 之前；失敗、取消或過期 response 不觸發。
- 新增 FabGrid `allowMultiSorting` option，預設為 `true`；設為 `false` 時，Header 的 `Shift + 點擊` 與 `toggleSort(colIndex, true)` 都退回單欄排序，只保留目前操作欄位，排序事件的 `multiSort` 同步為 `false`。
- 新增 `fabui.setConfig(options)`／`fabui.getConfig()` 全域設定 API，目前支援 `request.credentials`；全域值作為之後建立之 FabGrid 內建 `url` 請求預設，單一 Grid 的 `credentials` 優先，自訂 loader 不套用。`getConfig()` 回傳獨立副本。
- 新增 FabGrid 公開 `credentials` option，預設為 `'same-origin'`，另支援 `'include'` 與 `'omit'`；內建 `url` 模式會將此設定傳給 Fetch，使用 `'include'` 時等同 jQuery `xhrFields.withCredentials: true`，可帶送跨來源 PHP Session Cookie。Vue wrapper 維持原狀。
- 新增 FabGrid Column `allowSorting` option，預設為 `true`；設為 `false` 時，滑鼠或 `toggleSort()` 都不會改變排序、不觸發排序事件，也不會在 `remote: true` 時送出查詢。`sortingColumn` option／event handler 回傳 `false` 時同樣取消本機與遠端排序。
- 補強 `sortingColumn` constructor option：改由排序流程直接呼叫，不再依賴先註冊成 Wijmo-compatible event handler；回傳 `false` 時，本機與遠端都取消排序，其他已註冊的 `sortingColumn` handlers 仍會收到一次 `e.cancel === true`。
- 擴充 `unselectRow(row?)` 支援單選模式：可取消目前 selected row，成功後 `selectedRows`／`selectedItems` 回傳空陣列、列選取背景消失，並在排序、篩選與 refresh 後維持未選取；省略 `row` 時取消目前列，指定非目前列或已無 selected row 時回傳 `false`。Active cell 不納入此 API 契約。
- 新增不可取消的公開事件 `selectedRowChanged`，同時支援 constructor option、Wijmo-compatible `addHandler()` 與既有 native emitter。滑鼠／鍵盤／API 換列或取消 selected row 時回傳 `reason: 'selection'`；`setItemsSource()`、遠端資料回傳與 `observeItemsSource` mutation 更新資料來源時，即使 row index 相同也回傳 `reason: 'itemsSource'`。事件參數包含目前與先前的 row index／data item；同列只換 active column 或更新前後皆無 selected row 時不觸發。
- 調整 `selectionMode: 'CellRange'` 的互動與視覺：資料 cell 拖曳使用資料列選取背景，active cell 保留一般背景，範圍四周外框共用 `activeCellBorder`；列號點擊會選取該列所有可見欄位，沿列號拖曳可選取連續整列範圍。
- 修正 CellRange active cell 視覺：多格範圍的 active cell 維持一般背景，並補齊與單格選取相同的四邊框；與範圍外框重疊的邊由既有 perimeter border 繪製，其餘邊由 active overlay 補齊，粗細仍完全沿用 `activeCellBorder`。
