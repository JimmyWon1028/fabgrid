## 完成進度

- 統一 FabGrid constructor option、`grid.on()` 與 `addHandler()` 的事件 callback 為 `(grid, eventArgs)`，並讓所有事件參數固定提供 `grid`、`type` 與 `cancel`。
- 將原本只能透過 `grid.on()` 監聽的事件納入正式 Event object，並將 `cellEditStarting`、`cellCopied` 改為不重複派送的相容事件別名。
- 統一 FabGrid 公開方法的數字欄位參數為完整 `grid.columns` index；隱藏欄位仍可由資料 API 讀寫，畫面操作則安全拒絕。
- 統一 `selectionChanging`／`selectionChanged` 的完整座標、可見座標與列選取欄位，取消列選取及全部列操作不再回傳不同形狀的參數。
- 移除尚未由程式流程觸發的相容事件定義，避免公開永遠不會發生的 Event object。
- 讓 `updatingLayout` 與 `excelExporting` 支援取消，取消後不更新版面、不進入匯出 busy 狀態或下載檔案。
- 修正 `updatingLayout` 取消後仍繼續 render 或完成事件的流程，並讓欄位顯示、欄位重排、AutoFit 與 resize 在取消時回復本次變更。
- 將同一動作的前置與完成事件參數拆成獨立物件，避免保留的 `e.type`／`e.grid` 被後續事件改寫。
- 統一公開欄位參數接受十進位整數字串作為完整 `grid.columns` index。
- 修正 `updatingView` 取消 render 後，`refresh()` 仍誤觸發 `refreshed` 並回傳成功的流程。
- 修正 AutoFit／resize 的 layout 取消流程，精確還原 Column 原始 `width` 與內部計算寬度。
- 統一 `treeColumn` 的數字與十進位整數字串為完整 `grid.columns` index。
- 新增 Excel 自訂工作表名稱與 `fabui.Excel` 多工作表匯出，支援將多個 Grid 合併為同一個 XLSX。
- 新增 RowHeader 整列選取與剪貼簿行為，RowHeader 維持原本外觀，點擊列號後可用 `Ctrl/Cmd + C` 複製該列所有可見欄位。
- 將 Footer aggregate 改為依資料 view 快取，cell 編輯、資料更新、排序、篩選、分頁與 `invalidate()` 後標記 dirty，下一次 render 只重畫 Footer，讓公式更新其他唯讀 cell 時也能立即更新總計，並新增 `refreshFooter()` 供外部狀態變更時手動更新。
- 修正 PivotGrid 初始化期間 Header 高度方法互相呼叫造成的無限遞迴，尚未建立 Pivot view 時改用 FabGrid 基底 Header 高度。
- 將 PivotPanel 的 Fields 區固定為可用高度的一半並限制在區內垂直捲動，下方四個 View 區域平均使用剩餘高度。
- 讓 PivotGrid 欄寬調整回寫對應 `PivotField.width` 並納入 `viewDefinition`；相同 Value Field 產生的多個資料欄會同步欄寬。
- 新增 PivotPanel 三區拖放落點：目標上方／下方插入，中央合併為可序列化的文字組合欄位；組合來源與空白分隔規則會隨 `viewDefinition` 保存。
