## 完成進度

- 統一 FabGrid constructor option、`grid.on()` 與 `addHandler()` 的事件 callback 為 `(grid, eventArgs)`，並讓所有事件參數固定提供 `grid`、`type` 與 `cancel`。
- 將原本只能透過 `grid.on()` 監聽的事件納入正式 Event object，並將 `cellEditStarting`、`cellCopied` 改為不重複派送的相容事件別名。
- 統一 FabGrid 公開方法的數字欄位參數為完整 `grid.columns` index；隱藏欄位仍可由資料 API 讀寫，畫面操作則安全拒絕。
- 統一 `selectionChanging`／`selectionChanged` 的完整座標、可見座標與列選取欄位，取消列選取及全部列操作不再回傳不同形狀的參數。
- 移除尚未由程式流程觸發的相容事件定義，避免公開永遠不會發生的 Event object。
- 讓 `updatingLayout` 與 `excelExporting` 支援取消，取消後不更新版面、不進入匯出 busy 狀態或下載檔案。
- 修正 `updatingLayout` 取消後仍繼續 render 或完成事件的流程，並讓欄位顯示、欄位重排、AutoFit 與 resize 在取消時回復本次變更。
- 將同一動作的前置與完成事件參數拆成獨立物件，避免保留的 `e.type`／`e.grid` 被後續事件改寫。
- 統一公開欄位參數接受十進位整數字串作為完整 `grid.columns` index。
