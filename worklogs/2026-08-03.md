## 完成進度

- 修正 FabGrid cell editor 與 Search Row 的外部 `iconCls` 背景圖被內建樣式覆蓋，外部普通 CSS class 現在可直接定義 icon，不需要加上 `:root` 或 `!important`。
- 修正 FabGrid 在最後一個可編輯欄位按 Enter 時無法接續編輯下一列；現在 Enter 會移到下一列第一個可編輯 cell，Shift+Enter 可反向跨列。
- 修正 FabGrid 捲動到底部後刪除資料時，瀏覽器縮減 `scrollTop` 但固定欄、列標頭與選取層仍偏移一列的問題。
- 修正 FabGrid 公開事件的欄索引契約；選取、剪貼簿與編輯事件的 `e.col`、範圍欄位都會計入隱藏欄，並以對應的 `viewCol` 欄位提供可見欄索引。
- 新增 FabGrid 與 EditBox 共用的 `charcase` 定義，套用於 `text`、`combo`、`color` editor，支援只轉換 ASCII 英文字母的 `upper`／`lower`，並保留中文、數字、空白與符號；`date`、`time`、`number` 不套用。
- 修正 FabGrid `invalidItems` 生命週期；刪除或移出資料列後會移除該列的同步與 pending 非同步錯誤，保留錯誤的列／欄索引會隨排序、篩選、分頁、重排及欄位顯示狀態同步更新。
- 新增 FabGrid 本機唯一值驗證 `args.isDuplicate()`，自動檢查同一 Column 的完整資料來源並排除目前資料列；非空白值只允許出現一次，空白可重複，並支援忽略大小寫、巢狀 binding 與 TreeGrid。
