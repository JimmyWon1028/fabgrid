## 完成進度

- FabUI core 與獨立附加元件改為只內建英文；繁中與簡中集中為可按需載入的完整語言包。
- 語言包載入後會自動設為全域顯示語言並更新既有控件；指定尚未載入的語言時回退英文。
- FabGrid Demo 只在使用者選擇繁中或簡中時載入對應語言包，不再預先載入全部語言。
- 發佈目錄新增 Core 與獨立附加元件共用的繁中、簡中語言檔。
- FabGrid cell editor 固定與唯一 active cell 同步；滑鼠移出 edit cell 時維持編輯，只有點擊或程式選取其他 cell 時才取消目前編輯。
- 多語系發佈補上英文語言檔；未載入任何語言檔時仍預設英文，明確載入英文檔時會切回英文顯示。
- FabGrid 開發版與正式版主 Demo 預設關閉編輯；勾選工具列「編輯」只開放既有編輯操作，`editMode` 維持 `false`，單擊 cell 不會直接進入編輯。
- FabGrid 在 `editMode: false` 的編輯狀態下，Enter、Shift+Enter、Tab 與 Shift+Tab 改為提交並結束編輯，方向鍵保留 editor 內的字元游標操作；`editMode: true` 的連續換格編輯維持不變。
- FabGrid 開發版與正式版主 Demo 新增獨立 `editMode` 開關；「編輯」控制是否允許編輯，`editMode` 控制單擊進入與連續換格編輯，兩者分別保存。
- FabGrid 在允許編輯且 `editMode: false` 時，直接於 active cell 輸入可用字元會自動開始編輯，並以首個字元取代原內容。
- 英文語言包補齊為與繁中、簡中相同的完整訊息結構，可明確載入並切回英文。
- Build 指令新增 `build locale` 與 `build locale min`，分別產生完整語言檔與只保留壓縮語言檔。
- FabUI 語言檔改採 EasyUI locale 的覆蓋模式；語言檔載入後直接套用語言，fabLoader 保持獨立並沿用一般 script 快取。
