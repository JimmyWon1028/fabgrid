## 完成進度

- FabGrid 新增唯讀 `selectedRow` property，回傳目前 active cell 所在列的 `Row`／`GroupRow` instance；可由 `.index` 取得目前 active row index、由 `.dataItem` 取得資料，沒有可用列時回傳 `null`。此屬性與 `selectedRows` 的列選取狀態分離，`unselectRow()` 後仍保留 active row。
- FabGrid 新增 `stopNavigation`，預設為 `false`，支援 constructor option 與 runtime property。
- `stopNavigation = true` 時暫停使用者的鍵盤導覽、cell／row 點選、滑鼠滾輪、觸控與捲軸操作；目前 selected row 與 viewport 保持不變。
- 修正 runtime 設定 `stopNavigation = true` 後可能被 options／layout 同步覆寫為 `false`，導致方向鍵仍可操作；鎖定狀態改由 Grid instance 持有並同步回 options。
- `select()`、`selectRow()`、`scrollIntoView()`、`scrollPosition` 與資料更新 API 不受 `stopNavigation` 限制。
- 新增 option、runtime 切換、使用者事件封鎖與 API 仍可操作的 regression tests。
- 新增 `test/stop-navigation-source.html` 真實 DOM 測試頁；瀏覽器確認鎖定時滑鼠、方向鍵與滾輪不改變 selection／viewport，API 仍可移動，解除後操作立即恢復，Console 無錯誤。
- FabGrid 新增唯讀 `hasFocus` property，可直接判斷目前 `document.activeElement` 是否位於該 Grid root 內；多 Grid 畫面同一時間最多只有一個 Grid 回傳 `true`。
- 瀏覽器確認 Grid focus 時 `hasFocus === true`、焦點移到外部按鈕時為 `false`、重新 focus Grid 後恢復為 `true`，Console 無錯誤。
- 修正 `select()` 將越界 index clamp 成有效列／欄的行為；Row 或 Column index 不在目前可用範圍時現在直接回傳 `false` 且不改變 selection，`select(-1)` 不再造成第一列短暫閃爍。
- 移除 `mono-red` 與 `mono-green` theme；公開元件統一改為 17 組 theme metadata，Demo、Theme build、測試與文件只保留 `mono` 單色主題。
- 修正 16 組既有 Theme 的 component variables 因無效 `:root :root` selector 未套用到 EditBox；`dev-editbox.html` 與正式 Demo 現在會正確顯示目前外部 Theme CSS，且不再以 runtime theme class 切換。
- `fabui.Layout` 新增 `hide(region)`、`show(region)`、`isVisible(region)` 與 `hidden` region option；隱藏 edge region 時 Panel、Splitter、collapsed bar 與版面空間完全移除，但保留原本的尺寸、collapsed 狀態與 Panel instance。
- Layout Demo 為 north、south、west、east 增加獨立的「隱藏／顯示」按鈕，與既有 collapse／expand 控制分離。
