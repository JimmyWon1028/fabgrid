## 完成進度

- 修正 Tree 外部主題的 sprite 與 loading icon 路徑解析，讓 Default 以外的主題也能正常顯示節點、展開、checkbox、線條與載入圖示。
- 新增獨立 FabUI jQuery 相容 Wrapper，轉接 ERP 舊程式需要的 EasyUI 風格 plugin、`easyui-*` parser 與 `data-options`；Grid 僅使用獨立的 `$.fn.fabgrid` Wrapper，不提供 `$.fn.datagrid` 別名，也不改變 FabUI core 元件行為。
- FabUI jQuery Wrapper 新增通用 `EditBox` 入口，可用 `type` 選擇 `text`、`number`、`time`、`date`、`combo` 或 `color`，並與既有 EditBox 相容入口共用同一元件 instance。
- FabUI jQuery Wrapper 新增 `$.fn.splitbutton` 對應既有 `fabui.SplitButton`；`tabs('tabs')` 與 `tabs('getTabs')` 改回傳 jQuery Panel 陣列，保留 ERP 舊程式逐頁呼叫 `find()`／`panel()` 的契約，未修改元件 Core。
- Tabs 標題支援可信任的 HTML markup，保留原始 `title` API 值，關閉按鈕的無障礙名稱改用渲染後的純文字。
