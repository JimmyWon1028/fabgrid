## 完成進度

- 將遠端 Search Row 改為非阻擋式背景查詢，在 Grid 中央顯示 loading，等待期間保留目前資料並允許繼續操作；新查詢會中止內建 Fetch，或放棄尚未完成的舊自訂 loader 回應，只套用最新結果。
- 移除 Search Row 左側 RowHeader 與 selection 固定 cell 的滑鼠雙擊清除動作，避免誤清除搜尋條件或發起遠端查詢。
- 新增可用列 index 或 key 存取的多列 Footer，包含獨立列頭、panel 讀寫、formatItem／hitTest 列座標、AutoFit 與 Excel 多列匯出，並保留既有單列 Footer 相容行為。
- Footer 的數字值預設靠右並顯示千位分隔，明確指定的 footerFormatter 仍可覆寫顯示文字。
- 移除 Column `minWidth`；未設定 `width` 時取 Grid `columnMinWidth`（預設 20px），明確設定的初始 width 可使用更小值。
- 新增 `FabGrid.CellMaker.makeLink()` 連結 cell template，產生真正的 anchor、支援 template/callback 文字與 click context，並提供一致的連結及選取文字色。
- 多選欄只在實際資料列顯示欄位背景與右側格線，資料列以下的空白區域改為沿用 Grid body 背景，並同步套用所有主題。
- Vue 2 wrapper 獨立 build 改為只輸出 `fabgrid-vue2.min.js`，移除未壓縮版與舊 `fabgrid-vue.min.js` 檔名。
- 修正 PivotPanel 合併欄位時重建全部 PivotField、導致 calculated field 與其他函式設定遺失的問題，並拒絕直接或間接循環的 combineFields。
- 修正 FabGrid 拖曳重排欄位後完整欄位 index 過期，以及多列 Footer 自訂值顯示到其他欄位的問題。
- 補齊列選取、取消與全選的 selectionChanging／rowSelectionChanging 可取消流程，以及對應的 selectionChanged／rowSelectionChanged 完成事件。
- 修正 Chart 將未指定的 itemsSource 轉成空陣列、導致 PivotChart 與相容 categories／series data 顯示「沒有資料」的問題。
- 將 Vue 2、FabGrid jQuery 與 FabUI jQuery 三個獨立 wrapper 納入 build all 發佈流程。
