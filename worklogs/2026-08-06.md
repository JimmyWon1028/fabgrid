## 完成進度

- fabLoader 文字／HTML／XML 原文快取新增可設定的 `maxEntries` 與 LRU 淘汰，預設最多保留 100 筆已完成紀錄。
- fabLoader 新增 `clearResourceCache()`，可清除已完成的 Script、CSS 與圖片去重紀錄，不取消載入中的工作或移除既有 DOM。
- `mountHtml()` 相對路徑改寫擴充至 `srcset`、`formaction`、`object[data]` 與 inline style `url()`，並明確定義下載、外部 script、module 與 inline runtime error 的處理邊界。
- `mountHtml()` 重複掛載、追加掛載、下載失敗、無效 target 與 script 載入失敗行為完成收尾。
- FabGrid 垂直與水平捲動改為重用仍在 viewport 範圍內的 body cell、列首與多選 cell DOM，只建立新進入範圍的節點。
- Quick Search 新增重複條件結果快取，連續縮小搜尋條件時改由前次符合列繼續篩選；資料失效時同步清除快取。
- FabGrid 效能檢查新增可失敗的數值門檻與真實 Chrome DOM 重用回歸入口。
