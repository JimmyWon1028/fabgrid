## 完成進度

- 一般本機 FabGrid 與 Chart 共用 `fabui.collections.CollectionView` 時，Grid 排序會同步更新 CollectionView 順序並讓 Chart 依相同順序重繪；使用端不需要修改既有程式碼。
- Loader 發佈模式拆分為 `fabloader` 與 `loader`：前者將 fabDom 合併進 `fabLoader.*`，後者只打包純 fabLoader；兩者都支援一般與 min-only 輸出。
- `dataType: 'number'` 的本機 Grid、CollectionView 與 TreeGrid 排序會先移除字串值中的半形千位逗號與空白，再依實際數值排序。
- 非凍結欄水平捲動到右側後，排序只將垂直位置回到第一列；直接呼叫 `toggleSort()` 或點擊已完整可見的 Header 會保留水平位置，點擊部分被遮住的 Header 則只調整到整欄剛好可見。
- `remote: true` 的 `itemsSource` 可接受 Array 或 `fabui.collections.CollectionView`；遠端 rows 會更新對應資料來源，CollectionView 維持同一 instance 並同步共用 Chart，不再因本機重複篩選而顯示空白。
- FabGrid 新增 `clearSort()`，可一次清除所有單欄／多欄排序；本機與 CollectionView 立即恢復原始順序，遠端模式回到第 1 頁並只重新載入一次。
- FabGrid 新增 `getFilterState()` 與 `getSortState()`，可取得完整且不暴露內部可變物件的篩選／排序狀態快照。
- FabGrid 欄位定義支援巢狀 `columns` 合併多層 Header；葉欄位 API 保持扁平，群組會隨欄位顯示狀態重算範圍，Search Row、排序、篩選、resize 與 `hitTest().mergedRange` 依多列 Header 正確運作，`dev-grid.html` 展示「規格／寬、高、深」群組欄位。
- FabGrid 左右凍結欄改以完整欄位順序決定範圍；hidden 欄位仍計入 `frozenColumns`／`frozenRightColumns` 指定數量，不再讓凍結 pane 多吃後方可見欄位。
- FabGrid Column 新增 `cssClass`，可在初始化欄位定義中指定一個或多個 class，統一套用到該欄所有 body 資料 cell；`dev-grid.html` 的規格欄展示此設定。
- FabGrid 新增可巢狀的 `beginUpdate()`／`endUpdate()`、`deferUpdate()` 與唯讀 `isUpdating`，批次修改期間延後 View 更新並在最外層結束時合併為一次。
- FabGrid `color` cell editor 與 Color EditBox 點選 palette 色票後會立即關閉 popup；HSV／Alpha 拖曳調色仍保持 popup 開啟。
- FabGrid 的 `text`、`number`、`time`、`date`、`combo`、`color` cell editor 在焦點離開 Grid 時會統一驗證並寫回目前值；進入該 editor 的 popup 不會誤提交，從 popup 再離開 Grid 時才提交。
- `fabui.EditBox` 的六種 editor 在焦點離開控件時會統一驗證並提交目前值；進入自己的 Date／Combo／Color popup 不會提前提交，從 popup 再離開控件時才提交。
- FabGrid Column 的唯讀設定只保留 `isReadOnly`；`readOnly` 相容名稱已移除，Grid 可編輯時，Column 唯讀仍會禁止滑鼠、鍵盤與 `startEditing()` 開始編輯。
- FabGrid Column 新增預設為 `false` 的 `isRequired`；啟用後空值會自動以 required error 加入 `invalidItems`，有效值會清除錯誤，`0` 與 `false` 不視為空值。
- FabGrid 時間欄統一使用 `dataType: 'string'` 搭配 `editor: 'time'`；`editor: 'date'` 同時支援字串與 Date 資料型別，Date 值也可由 `dataType: 'date'` 自動選擇 editor。`mask`、`autoUnmask` 與遮罩字面值設定統一由 Column 提供，舊版 editor 層設定會在初始化時正規化到 Column，Grid Demo 也改用 Column 寫法。
- FabGrid Column 與 `fabui.EditBox` 的所有 editor 類型，`autoUnmask` 預設統一為 `false`；只有明確設為 `true` 時才移除遮罩字面值。
- FabGrid column footer 的水平內距與 body cell 統一，右對齊數字現在會和同欄資料精準對齊。
- FabGrid Column 新增預設為 `false` 的 `multiLine`；文字 editor 啟用後可保存輸入或貼入的多行值，Enter、Tab 與方向鍵維持原本的提交和移動行為，cell 顯示仍保持單行。
