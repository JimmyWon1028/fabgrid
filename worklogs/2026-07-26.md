## 完成進度

- 修正 FabGrid 連續 cell 編輯超出可視區時整段跳到頂端的問題。
- `Enter`、`Tab`、`ArrowUp` 與 `ArrowDown` 編輯導航改為先更新 active cell，再由 `scrollIntoView()` 做最小幅度捲動。
- 保留公開 `select(row, col?)` 對未完整顯示列採首列對齊的既有契約。
- 新增 Grid API regression test，並以 `demo/dev-grid.html` 驗證 active editor 到達底部後每次向下捲動一列。
- 將 Chart 公開 API 改為 Wijmo-style `fabui.chart` namespace，提供 `Chart`、`Pie`、`ChartType`、`Position`、`SelectionMode` 與 `animation`，並移除頂層 `fabui.Chart`。
- `fabui.chart.Pie` 建立時固定使用 Pie renderer，並同步更新 PivotChart 依賴、Demo、測試與 API 文件。
- 新增 `fabui.chart.animation.ChartAnimation`，支援 Chart／Pie、`AnimationMode`、座標軸動畫、duration、easing、`animate()` 與 Wijmo-style `ended` event。
- 新增 `fabui.collections.CollectionView`；FabGrid 與 Chart `itemsSource` 同時接受 Array 或 CollectionView，共用 view 時透過 `collectionChanged` 同步篩選、透過 `currentChanged` 同步選取。
- 移除 Chart `selectionSource`，並將 Grid／Chart Demo 改為共用同一個 CollectionView，不再手動監聽 `filterChanged`。
