## 完成進度

- FabGrid `remote: true` 的相容 `op` 補齊比較符號映射：`>=`、`>`、`<=`、`<`、`<>`、`=` 分別對應 Search Row 的 `gte`、`gt`、`lte`、`lt`、`ne`、`eq`；既有萬用字元符號維持不變，遠端 request 仍保留原始 `op`。`in` 的陣列序列化明確支援不分大小寫並保留輸入大小寫，Search Row 顯示 `IN`。
- 修正 `remote: true` 的空值初始化規則：對應 column 的相容 `op` 即使 `value: ""`，仍會初始化 Search Row operator 與 filter icon；空白 Search input 不會產生或送出該欄位的篩選規則，輸入內容後才沿用原始 `op`，再次清空即停止篩選。
- 調整 FabGrid Header sort 視覺：排序箭頭改為在既有 `22px` 容器內靠底排列並保留 `4px` 底距，使符號下緣與欄位文字行框下緣對齊；多欄排序序號仍位於箭頭上方。
- 新增獨立 Theme CLI build：`npm run build:theme` 只重建 `dist/theme/` 的 19 組一般／壓縮 CSS 與必要圖片，`npm run build:theme -- min` 只保留壓縮 CSS 與圖片；core 與獨立 Theme build 共用 `build/theme-builder.cjs`。
- 重整 Theme 發佈架構：`fabui.css`／`fabui.min.css` 與 Lite CSS 只包含共用樣式及 Default 配色，其他 18 組 Theme 改為固定 component selector 的獨立 CSS，不再依賴 `fg-theme-*` class；Demo 選擇 theme 時改由 query string 載入外部 Theme CSS 並重新載入頁面，同步調整 Theme builder 與 Mono SVG 繼承。
- 修正窄欄位 Header 的 filter icon 清晰度：文字內容固定在 icon 左側裁切，不再延伸到 icon 下方；一般 funnel 與 active operator icon 均向右微調 `2px`，並保留原有 hit area。
- 修正 filter icon 間距調整方向：還原窄欄位 Header 的 `24px` 文字裁切保留區，改將 funnel 圖形在 hit area 內的左側內距由 `4px` 縮小為 `2px`，stem 同步左移 `2px`；保留 icon 的右側 `-2px` 定位、hit area 與 Header resize handle 行為。
- 依實際 icon 幾何修正窄欄位 sort／filter 間距：排序啟用時為 Header 增加 sorted 狀態，將 sort icon 固定到 filter funnel 左側並維持 `2px` 可視間距，文字則裁切於 sort icon 左側；一般寬度或未排序 Header 維持原排列。
- 加深 Default 主題切換運算符後的 filter icon 顏色：active operator 由較淺的 `#3b82f6` 改為標準 `blue`（`#0000ff`），一般漏斗與 Excel-like active 狀態維持原樣。
- 修正 `remote: true` 的 Excel-like 值篩選候選值：首次開啟時快取欄位完整候選值，套用後即使遠端資料只回傳已勾選值，重新開啟同一欄位仍顯示原完整集合，並以目前 filter values 還原勾選狀態。
- 調整 Default 主題的運算符 filter icon：維持標準 `blue`（`#0000ff`），字重由 `bold` 改為 `normal`，不再加粗。
- 修正 `build:lite` 對尾端 `min` 參數的處理與 browser-global 壓縮方式：`npm run build:lite -- min` 現在只產生並保留 `dist/fabui.lite.min.js`、`dist/fabui.lite.min.css` 與必要圖片，不再留下 Lite 非壓縮檔，且壓縮版可直接公開 `fabui` API。
- 修正 Diagram 獨立發佈檔名契約：公開物件為 `fabui.Diagram`，因此 bundle 統一改為 `dist/fabui.diagram.js`、`dist/fabui.diagram.min.js`、`dist/fabui.diagram.css`、`dist/fabui.diagram.min.css`。
- 統一運算符 filter icon 的主題色：Default 與其餘淺色主題使用一般字重 `blue`，`black`／`dark-hive` 深色主題使用白色；改由 `--fg-filter-operator-color` 共用變數控制。
- 統一 FabGrid 欄位篩選設定為 `filterMode: false | Array<'excel' | 'searchRow'>`：陣列第一項為目前模式，單一項目只開放該模式，空陣列或無效值關閉兩者；移除 `showSearchRow` option、method 與 event。`filterRules` 只在 Search Row 為可用模式時處理。
- 補強 `filterMode` 順序契約：正規化後陣列第一項為預設及目前篩選模式，只有 `array.length > 1` 時 Header 右鍵功能表才顯示篩選方式切換；單一模式、`false` 與空陣列都不顯示切換項目。
- 修正 FabGrid runtime layout 正規化會把 `filterMode` 重設為預設值的問題：Header 右鍵現在可在 Excel-like／Search Row 間切換，上方「篩選」開關也能正確停用與重新啟用篩選；`dev-grid.html` 改為保存新的 `filterMode` 狀態並相容舊 `allowFiltering`／`showSearchRow` localStorage 設定。
- 調整窄欄位 Header 文字顯示：判定欄寬不足時不再為 filter／sort icon 預留右側裁切空間，文字可延伸並重疊顯示於 icon 下方；一般寬度、icon 固定位置、排序間距、點擊區與 resize handle 層級維持不變。
- 修正右對齊窄 Header 在切換排序時的文字位移：右對齊 Header 固定保留 `24px` 右側空間，不再因 sort icon 讓窄欄位判定改變而向右跳動；一般左對齊窄欄位仍可讓文字重疊 filter／sort icon。
- 修正數字／右對齊窄 Header 的 filter icon 重疊規則：移除右對齊欄位的保留空間，使文字與一般文字欄位相同，可延伸並重疊顯示於 filter icon 下方；窄欄位判定固定預先計入 sort icon 寬度，確保排序前後文字位置不跳動。
- 調整右對齊數字 Header 的自適應外側間距：完整標題仍可顯示時，右側保留與左對齊文字 Header 左側相同的 `6px`；空間不足時自動降為 `0px`，讓文字繼續延伸至 filter icon 下方。
- 修正足夠寬的右對齊數字 Header 仍與 filter icon 重疊：改為三段式判定，欄寬足以容納完整標題與 icon 時使用 `24px` icon 空間且不重疊，稍窄時保留 `6px` 外側間距並允許重疊，再窄時才降為 `0px`。右對齊 sort icon 改為絕對定位，維持排序前後文字位置不變。
- 調整 `remote: true` 的 `filterRules.op` 送出契約：GET／POST request 與 `getFilterRules()` 不再送出已知標準名稱，文字 operator 統一轉為 `..%`、`%..%`、`%..`、`!..%`、`!%..%`、`!%..`，比較 operator 統一轉為 `>=`、`>`、`<=`、`<`、`<>`、`=`；既有相容符號保持不變，沒有對應符號的自訂 `op` 與不分大小寫的 `in` 仍原樣送出。
- 將 FabGrid Search Row 的 `searchDelay` 預設值由 `200ms` 調整為 `500ms`，本機與 `remote: true` 共用相同 debounce。
- 修正遠端大量資料載入後，垂直捲動軸使 client width 變窄時誤出現橫向捲動軸：Size layer 的 inline width 改為只使用實際欄位總寬，空間有餘時交由 CSS `min-width: 100%` 跟隨即時可用寬度。
- 修正 Search Row input 的 `Enter`／`Shift+Enter` 行為：兩者不再取消 debounce timer 或立即套用／送出遠端查詢，僅攔截按鍵與外層表單預設提交；輸入內容仍依 `searchDelay` 套用，`Tab` 導覽維持不變。
- 修正上一版 Search Row 按鍵處理遺漏導覽的問題：`Enter`／`Tab` 恢復移到下一個可見欄位 input，`Shift+Enter`／`Shift+Tab` 移到上一個；四者都保留既有 debounce timer，不立即套用或送出遠端查詢。
- 將 Search Row `searchDelay` 預設值由 `500ms` 調整為 `400ms`。
- 調整 Search Row 欄位導覽焦點：透過 `Enter`／`Tab`／`Shift+Enter`／`Shift+Tab` 移到下一個或上一個可見欄位時，若目標 input 已有內容就全選，空白 input 維持一般游標。
- 修正 FabGrid constructor options 只有 `updatedView` 被綁定的問題：建立 Wijmo-compatible events 後改為逐一綁定所有同名 option callback，使 `selectionChanged: (g, e) => {}` 與其他公開事件可正常觸發。
- 修正凍結欄後方的非凍結欄寬於可用視窗時，點選該欄會錯誤向右捲動並讓欄位內容被凍結區遮住的問題；`scrollIntoView()` 現在優先把過寬欄位的左緣對齊凍結欄右側。
- 全面整理 API 手冊：新增文件索引、`fabui.Control` 與 Theme 共用手冊；補齊 Calendar、Diagram、Gantt、Layout、Panel、PropertyGrid、Radio、Window 等公開選項，校正獨立 bundle、Theme CSS 與 wrapper 暫緩契約，刪除或改寫舊 runtime theme class 說明，並縮短過長段落。
